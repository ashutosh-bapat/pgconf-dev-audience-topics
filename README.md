# pgconf-dev audience topics

This repository is a lightweight public hub for community-requested talk topics for pgconf.dev.

## How to participate

1. Open GitHub Discussions in this repository and create a topic request (or comment on an existing one).
2. Use upvotes and comments to signal what topics you most want to see at the conference.
3. Search first and add support to existing discussions when a similar request already exists.

## Important expectations

- Final talk selection still happens through pgconf.dev's existing speaker proposal and program selection process.
- Discussion upvotes are a signal of community interest, not a guarantee that a topic will be scheduled.
- Moderators may close duplicate requests and direct participants to a canonical discussion so support is not split.
- Suggested speakers are welcome, but nomination does not imply commitment or acceptance.

## Suggested speaker guidance

If you suggest a speaker, please keep discussion respectful and constructive:

- suggest speakers based on fit and expertise for the topic
- avoid pressure or assumptions that someone is available
- include context (links to talks, posts, or projects) when possible

For full workflow details, see:

- `/docs/community-process.md`
- `/docs/topic-request-template.md`
